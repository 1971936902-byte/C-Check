# AI 智能助手开发验收记录

日期：2026-10-28。代码分支：`codex/ai-assistant`。本记录针对功能开发，不代表发布或现网升级完成。

## 需求对应证据

| 需求 | 实现与验证 |
| --- | --- |
| 侧边栏助手与 Qwen 对话 | `AppLayout.vue`、`AssistantView.vue` 与助手 API；真实浏览器完成登录、导航、发送及停止生成。 |
| 使用现有 Qwen2.5 FP8 和 Jina | 私有提供方和网关复用现有模型；编译版独立容器 GPU 全栈通过，未使用 A3B 分支或更换模型。 |
| RAG 与单个/批量文件上传 | 文档 API、专用 Celery 工作者、AnythingLLM；真实批量上传经 GPU Jina 入库，回答包含测试文件事实与引用，个人文件按用户隔离。 |
| 审查期间禁用助手 | 页面输入与上传控件禁用；服务端在忙碌时拒绝新聊天。真实浏览器与公共 API 均验证，不依赖页面状态保护模型。 |
| 审查优先并中断聊天 | 实际长聊天产生 token 后提交审查；聊天被中断，审查完成并可下载 JSON、Markdown、PDF，随后聊天恢复。 |
| 不因连接断开而错误释放 GPU | 持久调度标识与受控取消；测试覆盖旧任务、新占用、模型进程代次与失败关闭。真实恢复验证旧占用清理、文件重试和旧任务不能释放新占用。 |
| 历史、用户隔离与页面适配 | 实际后端浏览器测试通过历史刷新、被中断历史、用户隔离；检查 1440、768、390 像素视口，无页面异常或横向溢出。 |
| 稳定开源组件与部署接入 | 上游提交与依赖锁、补丁、MIT 许可校验；提供方镜像、资源防篡改、私有目录权限和 Compose 配方验证通过。安装器及发布器增加显式助手选项。 |
