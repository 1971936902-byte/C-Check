# 受管终端验收记录

日期：2026-10-28。目标发布版本为 rc21，原 rc20 保持不变。
以下是签名前的隔离验收，不等同于已发布、目标 RTX5880 现网验收或现网升级。

## 已完成

- Linux 编译服务器执行 203 项发布工具测试，全部通过；Windows 同批测试有 10 项环境跳过。
- 终端独立单元测试 9 项通过，包括镜像摘要、离线模式、项目隔离和受管连接 SQL。
- 前端 65 项测试通过，类型检查与生产构建通过。
- 1440、768、390 三种宽度分别验证终端帮助独立页签、7 条管理命令、侧栏入口和无页面横向溢出。
- 更新后前端重新验证助手聊天、忙时禁用、打断提示和批量知识文件交互；此项为模拟 API 回归。
- 新前端候选镜像在非 root、只读、无网络、无 GPU 容器中通过助手和帮助页深链接检查。
- 使用一次性 Ed25519 测试密钥及独立目录、独立 PostgreSQL 数据卷安装受管终端；没有使用发布私钥。
- 缺少的镜像按固定 SHA256 下载。官方仓库首次拉取超时后，使用相同摘要的镜像源成功获取；没有修改版本锁。
- HTTPS 验证通过；默认 guacadmin/guacadmin、匿名访问和未授权用户创建连接均被拒绝。
- 普通用户默认看不到连接，授予 READ 后只能看到对应连接。
- `terminal-stop/start` 后初始凭据文件哈希、连接 ID、用户授权保留。
- `terminal-configure` 可修改连接参数；不重建账号，保留连接 ID/权限，清除连接中合成测试密码。
- Guacamole 权限响应为列表，初版测试误按字符串比较。保留原失败日志，使用原数据库重新核对 `['READ']` 后通过，没有重置数据库掩盖问题。
- 提供 Ed25519 公钥、实际协商 ECDSA 时连接被拒绝。改用可信控制台读取且与目标一致的 ECDSA 公钥后连接成功，没有关闭主机校验。
- 通过浏览器实际登录 Linux、执行 `id`/`uname`、中断 `sleep`；生成随机证明文件，使用独立 SSH/SFTP 核对内容和 UID 后删除，确认不是模拟回显。
- 桌面与手机均完成真实终端截图；测试结束停止本次独立终端容器，保留数据供发布升级验证。

## 证据

工作空间 `outputs/assistant`：

- `rc21-terminal-help-browser/verification.json` 与同目录截图。
- `rc21-assistant-browser/verification.json`：更新后助手模拟接口回归。
- `rc21-terminal-lifecycle.json`：TLS、账号与连接保留、配置和权限核对，绑定终端 4 个运行文件哈希。
- `rc21-terminal-real-browser/verification.json` 与同目录截图：真实 SSH、交互命令、Ctrl+C、证明文件核对及删除。

服务器保留初始超时、首次权限断言失败及重新核对记录。测试数据库与业务数据库隔离。
终端不申请 GPU、不挂载 Docker socket、不使用 privileged；SSH 密码没有写入站点配置或 Guacamole 数据库。
