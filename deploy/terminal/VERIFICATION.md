## 环境

- Ubuntu 22.04.3 LTS / x86_64，约 16GB 内存，无 GPU 需求。
- Docker 29.1.3 / Compose v2.39.4。
- 独立部署目录 `/opt/c-check-terminal`。
- Guacamole 与 guacd 1.6.0，其余组件的实际不可变版本见 `images.lock.json`。
- Guacamole 网页登录、数据库、SSH 连接均为真实运行。
- C-Check 集成预览使用模拟 API，只用于菜单、权限显示、跳转、刷新和布局测试；不代表真实业务后端或模型任务验收。

## 验证边界

- 浏览器自动化因自签名测试证书使用了 ignoreHTTPSErrors；另有独立证书校验测试通过。
- 未验证生产 CA/公网域名、SSO、SFTP、会话录像、多用户压力、跨机器灾备恢复或宿主机重启。
- SSH 测试账号 vipuser 属于 sudo/LXD 等宿主机组，本次未执行 sudo 命令；生产应配置最小权限专用账号。
- 初始网页密码和 SSH 密码没有加入源码、截图、静态配置或测试报告。
- 未来部署本功能到既有 RC19 前端仍需要交付包含菜单改动的新前端；本次没有修改生产实例。
